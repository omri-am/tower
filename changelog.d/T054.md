- `tower-locate` warns on stderr when its start directory or one of its ancestors has a `.git`
  entry but `git rev-parse --show-toplevel` fails there, for example in a Codex sandbox that
  cannot read `git` or a git config file. The warning names the directory and the first line of
  git's error, and says that the worktree mapping was skipped. `--quiet` silences it. The
  resolution, stdout and exit statuses do not change.
